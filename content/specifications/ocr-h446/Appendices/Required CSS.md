## Style attribute

You need to be able to style individual HTML elements with the `style` attribute.
```html
<h1 style="color: blue; font-family: sans-serif;">Important heading</h1>
```

## Style sheets
You be able to style:
- elements
- classes
- identifiers
```css
/* styling an element */
h1{
	color: blue;
}

/* styling a class */
.infoBox{
	background-color: green;
}

/* styling an identifier */
#menu {
	background-color: #A2441B;
}
```
## Required properties
You must be able to use the following CSS properties:
- `background-color`
- `border-color`
- `border-style`
- `border-width`
- `color` (both named and hex colours)
- `font-family`
- `font-size`
- `height`
- `width`

Other properties may be used in questions but will be explained in the question.
