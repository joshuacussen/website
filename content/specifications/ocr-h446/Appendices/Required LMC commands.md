
| Mneumonic | Instruction        | Alternative mnemonics accepted |
| --------- | ------------------ | ------------------------------ |
| `ADD`     | Add                |                                |
| `SUB`     | Subtract           |                                |
| `STA`     | Store              | `STO`                          |
| `LDA`     | Load               | `LOAD`                         |
| `BRA`     | Branch always      | `BR`                           |
| `BRZ`     | Branch if zero     | `BZ`                           |
| `BRP`     | Branch if positive | `BP`                           |
| `INP`     | Input              | `IN`, `INPUT`                  |
| `OUT`     | Output             |                                |
| `HLT`     | End program (halt) | `COB`, `END`                   |
| `DAT`     | Data location      |                                |
