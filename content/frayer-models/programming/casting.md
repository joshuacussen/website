## Definition
Converting a value from one [[data type]] to another.

## Characteristics
- Changes the data type of a value (e.g., [[integer]] to [[float]], [[Boolean data type|Boolean]] to [[string]])
- Common Python functions include:
	- `int()`
	- `float()`
	- `str()`
	- `bool()`

## Examples
- int to float: `float(5)` → `5.0`
- float to int: `int(3.14)` → `3`
- int to string: `str(5)` → `"5"`
- string to float: `float("2.1")` → `2.1`
- bool to string: `str(True)` → `"True"`
- int to bool: `bool(0)` → `False`
- int to bool: `bool(1)` → `True`

## Non-examples
- [[assign|Assignment]]: `x = 5`
- [[concatenate|Concatenation]]: `"hello " + "world"`
