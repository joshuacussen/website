## Definition
To create an [[object]] from a [[class]].

## Characteristics
- Creates a new object in [[random-access memory|memory]] using a class as a template
- Calls the class [[constructor]] to set the object's initial state

## Examples
- Instantiating a `Person` object (Python): `q = Person("Quintin")`

## Non-examples
- [[initialise|Initialising]] a [[variable]] (Python): `x = 5`
- [[declare|Declaring]] a variable (C): `int x;`
