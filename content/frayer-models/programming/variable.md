## Definition
A named location in [[random-access memory|memory]] that's value can change while the program is running.

## Characteristics
- Has an [[identifier]]
- Value can be updated using the `=` [[assign|assignment]] [[operator]]
- [[declare|declared]]: an identifier is given and memory reserved
- [[initialise|Initialised]]: given an initial value at the point of declaration or later
- Depending on the programming language, the [[data type]] of its value may be changeable

## Examples
- `name = "John"`
- `age = 16`
- `name = input("What is your name?")`
- `length = len(names)`

## Non-examples
- [[constant|Constants]] (e.g., `const x = 5`, `AGE = 5`)
